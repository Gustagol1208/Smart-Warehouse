COMO COLOCAR NO GITHUB
1. Abre https://github.com/Gustagol1208/Smart-Warehouse
2. Clica em Add file > Upload files.
3. Extrai este ZIP no computador.
4. Arrasta os 5 ficheiros para a área de upload (não coloques o ZIP dentro do repositório).
5. Clica em Commit changes.

COMO ATIVAR O GITHUB PAGES
1. No repositório, abre Settings > Pages.
2. Em Build and deployment, escolhe Deploy from a branch.
3. Branch: main; Folder: /(root).
4. Clica Save e aguarda a publicação.
